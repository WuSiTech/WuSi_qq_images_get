# QQ 聊天媒体提取（Win11 风格 GUI，高 DPI）

按 **聊天对象 + 开始/结束时间 + 保存目录** 提取 QQ 图片 / 视频 / 表情包，包含转发记录、
嵌套转发记录（每类可单独设置层数）以及一条消息里连发的多张图。

## 两种运行方式

- **免安装版（推荐）**：直接双击 `QQ聊天媒体提取.exe`。
  已把 Python、tkinter、cryptography 全部打包，**不需要安装 Python 或任何库**；
  手动选择数据库时会在 exe 同目录生成 `config.json` 记住路径。
- 源码方式：`python qq_group_images.py`（需要 `pip install cryptography`）。

## 界面说明

- **① QQ 进程与数据库密钥**
  - 「检测 QQ 进程并获取密钥」：检测运行中的 QQ 并提取数据库密钥；密钥可遮挡/显示，留空自动提取；
  - 数据库单选框：
    - `自动搜索`（默认）：自动在常见位置查找 `nt_msg.db`；
    - `选择数据库`：选到有效 `nt_msg.db` 才保持该项，取消/无效自动退回自动搜索；
    - `?`：解释数据库文件是什么；
    - 提示：没改过 QQ 的「聊天记录保存位置」就用自动搜索。
- **② 目标与时间**
  - 聊天类型：`群聊` / `个人（好友）`；号码必须是纯数字；
  - 开始/结束时间各占一行；保存目录、按内容去重。
- **③ 下载类型与来源**（默认全部不勾选）
  - 图片 / 视频 / 表情包三类，每类来源：
    `直接发送（单条）`、`合并消息发送（一条多图）`、`转发 / 嵌套转发`；
  - 每类独立「嵌套层数（仅转发）」：0 = 不限；2 = 只到第二层；
  - 灰字提示说明了转发记录正文的缓存机制与不集成 NapCat 的原因（封号风险）。

保存命名：`image_0001.jpg`、`video_0001.mp4`、`sticker_0001.gif`，按群里发送顺序编号；
转发/嵌套记录的图片在该条消息位置依次展开。

## 数据库定位（不是写死路径）

- 手动配置（`config.json`）> 环境变量（`QQ_MEDIA_DB` / `QQ_MEDIA_TENCENT_DIR`）> 自动扫描：
  `%USERPROFILE%\Documents\Tencent Files`、OneDrive 下、`C:\Users\Public\Documents`、
  各盘符（C~H）的 `Tencent Files` 等，账号目录不写死，取最近修改的。

## QQ 版本兼容性

- 只支持 **NTQQ（新版 QQ 9.9.x 架构）** Windows x64；**不支持老版 PC QQ（9.8 及更早）**；
- 同大版本内通常可用，腾讯改版后可能需要适配。

## 转发记录提示

转发/嵌套记录的正文由服务器保存，QQ 只在打开/渲染过之后才缓存到本地；未缓存的记录会在日志中
列出（应有/本地条数），在 QQ 里点开一次再重跑即可补全。未集成 NapCat 等第三方协议（封号风险）。

## 命令行（源码方式）

```
python qq_group_images.py --nogui --chat group --target 436043853 --start "2026-10-26 01:46" --end "2026-10-26 19:00" --out "D:\图片" --types image,sticker --sources single,merged,forward --depth 0
```
